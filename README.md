# 🌸 Perfumy – React Website

A simple and responsive **perfume webpage** built using **React.js** and basic React components. This project demonstrates how a single-page website can be divided into reusable components for better structure and maintainability.

## 📌 Project Overview

**Perfumy** is a simple perfume website that showcases different fragrance products and provides basic information about the brand.

The website contains a single page with the following sections:

* 🏠 **Home**
* 🌺 **Products**
* 📖 **About Us**
* 📞 **Contact Us**

The project focuses on using basic React components to create a clean and organized webpage.

## 🛠️ Technologies Used

* **React.js**
* **HTML5**
* **CSS3**

## 🧩 React Components

The webpage is divided into reusable components:

### 1. Navbar

The navigation bar contains the website name and navigation links for different sections of the page.

### 2. Cards

The Cards component is used to display perfume products in an organized layout.

Each card can contain:

* Perfume image
* Product name
* Product description
* Price or other product details

### 3. About

The About component provides information about the Perfumy website and its purpose.

### 4. Contact

The Contact component provides contact information and allows users to get in touch with the website.

## 🚀 How to Run the Project

### 1. Clone the repository

```bash
git clone <your-github-repository-url>
```

### 2. Navigate to the project folder

```bash
cd perfumy
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

The application will run on the local development server provided by Vite.
